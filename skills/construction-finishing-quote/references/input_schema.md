# مخطط بيانات الإدخال (spec.json)

يُمرَّر إلى `scripts/generate_quote.py`. الحقول المطلوبة مُعلَّمة بـ **(مطلوب)**.

| الحقل | النوع | الوصف |
|---|---|---|
| `quote_ref` | نص | **(مطلوب)** رقم العرض، مثال `"QT-2026-004"` |
| `date` | نص | تاريخ العرض `YYYY-MM-DD`. افتراضياً اليوم |
| `validity_days` | رقم | صلاحية العرض. افتراضياً `30` |
| `project_name` | نص | **(مطلوب)** اسم المشروع — يظهر تحت العنوان |
| `client_name` | نص | **(مطلوب)** اسم العميل مع اللقب |
| `project_location` | نص | **(مطلوب)** الحي والمدينة |
| `project_type` | نص | **(مطلوب)** `residential` أو `commercial` |
| `project_description` | نص | **(مطلوب)** فقرة وصف المشروع (2–4 أسطر) |
| `area_m2` | رقم | المساحة الإجمالية التقريبية (اختياري، تظهر في جدول البيانات) |
| `floors` | قائمة نصوص | مكونات المشروع، مثال `["الدور الأرضي","الدور الأول","الملحق"]` |
| `masonry_modification` | منطقي | `true` عند وجود تعديل مباني — يظهر في جدول البيانات |
| `scope_intro` | نص | استبدال فقرة تمهيد نطاق العمل الافتراضية (نادراً) |
| `scope_groups` | قائمة | **(مطلوب)** مجموعات نطاق العمل — انظر أدناه |
| `contract_value` | رقم | **(مطلوب)** قيمة العقد المقطوعة **غير شاملة** الضريبة |
| `price_line_label` | نص | وصف بند السعر في الجدول المالي |
| `vat_percent` | رقم | افتراضياً `15` |
| `duration_text` | نص | مدة التنفيذ، مثال `"مدة التنفيذ (150) يوماً تقويمياً."` |
| `warranty_text` | نص | مدة الضمان في الشروط. افتراضياً `"12 شهراً"` |
| `payment_schedule` | قائمة | استبدال جدول الدفعات الافتراضي — انظر أدناه |
| `exclusions` | قائمة نصوص | **استبدال** قائمة الاستثناءات الافتراضية بالكامل |
| `extra_exclusions` | قائمة نصوص | **إضافة** استثناءات خاصة بالمشروع (الأشيع) |
| `client_responsibilities` / `extra_client_responsibilities` | قائمة نصوص | نفس المنطق |
| `terms` / `extra_terms` | قائمة نصوص | نفس المنطق |

## `scope_groups`

```json
"scope_groups": [
  {
    "group_title": "المرحلة التمهيدية: أعمال تعديل المباني",
    "group_note": "تُنفَّذ قبل مباشرة أعمال التشطيب، وقيمتها مشمولة في إجمالي العقد.",
    "items": [
      {"title": "أعمال الهدم والإزالة", "text": "هدم وإزالة الجدران …"}
    ]
  },
  {
    "group_title": "أعمال التشطيب الرئيسية",
    "items": [
      {"title": "أعمال تمديدات السباكة والصرف الصحي (التأسيس)",
       "text": "توريد وتنفيذ كامل شبكات التغذية …",
       "bullets": ["دورات المياه: عدد (4)", "المطبخ: نقطة تغذية وصرف"]}
    ]
  }
]
```

- الترقيم متسلسل عبر كل المجموعات (1، 2، 3 …) ولا يعاد من الصفر لكل مجموعة.
- `group_title` و `group_note` و `bullets` اختيارية.
- المجموعة الثالثة في المشاريع التجارية: `"أعمال الديكور والتشطيبات الخاصة"`.

## `payment_schedule`

الافتراضي (لا تمرره إلا للتعديل): 30 / 20 / 20 / 20 / 10.

```json
"payment_schedule": [
  {"pct": 30, "label": "دفعة مقدمة", "milestone": "عند توقيع العقد …"},
  {"pct": 20, "milestone": "عند الانتهاء من …"}
]
```

يرفض السكريبت التوليد إذا لم يكن مجموع `pct` مساوياً لـ 100 بالضبط.

## ناتج السكريبت (stdout)

JSON يحتوي: `contract_value_excl_vat`, `vat`, `total_incl_vat`,
`amount_in_words` (التفقيط)، `scope_items_count`, `payment_percentages`,
`payment_check_sum`. راجع `total_incl_vat` و `amount_in_words` قبل التسليم.
