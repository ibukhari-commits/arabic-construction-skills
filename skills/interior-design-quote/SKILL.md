# عرض سعر خدمات التصميم — قالب لاستديوهات التصميم

يبني `scripts/generate_quote.py` عرضاً من 3 شرائح (الغلاف، العرض المالي مع جدول
الدفعات، مراحل العمل والشروط) **من الصفر** بتصميم محايد قابل للتخصيص، فلا يعتمد
على قالب جاهز ولا على مواقع أشكال ثابتة، ويتحمل 1–3 بنود تسعير أو أكثر.

## الإعداد الأولي (مرة واحدة)

1. انسخ `examples/company.example.json` إلى `company.json`: اسم الاستديو، وسطر
   التعريف، وبيانات التواصل، واللونان الأساسي والثانوي.
2. انسخ `examples/pricing.example.json` إلى `pricing.json` وضع **أسعارك أنت**.
   الأرقام الموجودة في المثال توضيحية فقط ولا تمثل أي سوق. لكل نوع خدمة: وصف
   يظهر في الجدول، ووحدة (م² أو واجهة)، وسعر الوحدة.
3. إن كانت سياسة استديوك تدمج بنداً في بند آخر (مثل تصميم الواجهات ضمن سعر
   التصميم التجاري) فاحذفه من `items` أو أعطه سعراً صفرياً في `pricing.json`
   — السكربت لا يفترض أي قاعدة تسعير.

## الخطوة 1 — اجمع موجز المشروع

اسأل صاحب الاستديو عمّا لم يذكره فقط:

1. **اسم العميل** واللقب (الأستاذ/الأستاذة) وصيغة الختام المقابلة (المحترم/المحترمة).
2. **وصف الفراغات** للفقرة التمهيدية — **اجعله قصيراً (حوالي 70 حرفاً)**؛ القوائم
   الطويلة تتراكب بصرياً مع رأس الجدول. لخّص بدل سرد كل مساحة.
3. **أنواع الخدمة** (داخلي سكني/تجاري، لاندسكيب، واجهات) وكمية كل منها.
4. **مدة العقد المقدرة** بأيام العمل — يحددها صاحب الاستديو، لا تُحسب من المساحة.
5. **رسوم التعديل الإضافي** وأيامه — **أكّدها قبل كل عرض** لأنها شرط تجاري قد يتغير.

## الخطوة 2 — ابنِ spec.json وشغّل

```bash
pip install python-pptx --break-system-packages
python scripts/generate_quote.py spec.json -o "عرض سعر - <العميل>.pptx" \
    --company company.json --pricing pricing.json
```

راجع `references/input_schema.md` و`examples/spec.example.json`. يطبع السكربت
`subtotal` و`vat` و`total` والدفعات — قارنها ذهنياً (المجموع ≈ الكمية × السعر × 1.15
لمشروع بنوع واحد) و`payments_sum_check` يجب أن تكون `true`.

نسب الدفعات الافتراضية 60 / 30 / 10 ويمكن تغييرها عبر `payment_split_percent`
(المجموع 100 تماماً، والأخيرة تمتص فرق التقريب).

## الخطوة 3 — فحص بصري (لا تتخطَّه)

```bash
soffice --headless --convert-to pdf "output.pptx" && pdftoppm -jpeg -r 80 output.pdf qa
```

افحص الشريحة 2 تحديداً: لا تداخل بين الجداول، ولا قصّ في آخر جدول الدفعات، والأرقام
مطابقة لما طبعه السكربت. إن ظهر خلل فعدّل البيانات (لا XML المخرجات) وأعد التشغيل.

## المرجع

- `scripts/generate_quote.py` — يبني الشرائح ويحسب الضريبة والدفعات.
- `references/input_schema.md` — مخطط `spec.json`.
- `examples/` — `spec` و`company` و`pricing` توضيحية.
