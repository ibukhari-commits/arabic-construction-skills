# مخطط بيانات الإدخال (spec.json)

يُمرَّر إلى `scripts/generate_quote.py` كملف JSON. كل الحقول التالية **مطلوبة** ما
لم يُذكر أنها اختيارية:

| الحقل | النوع | الوصف |
|---|---|---|
| `quote_ref` | نص | رقم العرض (يحدده المالك بنفسه، مثال: `"Q-2026-003"`) |
| `date` | نص (اختياري) | تاريخ العرض بصيغة `YYYY-MM-DD`. افتراضياً تاريخ اليوم |
| `validity_days` | رقم (اختياري) | مدة صلاحية العرض بالأيام. افتراضياً `30` |
| `project_name` | نص | اسم المشروع — يظهر كعنوان فرعي أعلى العرض ويُستخدم في اسم الملف الناتج |
| `client_name` | نص | اسم العميل كاملاً مع اللقب المناسب (الأستاذ/المهندس/إلخ) — يظهر كما هو في جدول الأطراف |
| `project_location` | نص | موقع/عنوان المشروع (حي، مدينة) |
| `floors` | قائمة نصوص | الأدوار **بالترتيب من الأسفل للأعلى**، كما ستظهر في نطاق العمل وجدول الدفعات. مثال: `["الدور الأرضي", "الدور الأول", "الملحق العلوي"]` |
| `area_m2` | رقم | المساحة التقديرية الإجمالية للمشروع بالمتر المربع |
| `rate_per_m2` | رقم | سعر المتر المربع بالريال السعودي، غير شامل الضريبة |
| `vat_percent` | رقم (اختياري) | نسبة ضريبة القيمة المضافة. افتراضياً `15` |
| `advance_pct` / `foundation_pct` / `final_pct` | رقم (اختياري) | نسب الدفعة المقدمة والأساسات والاحتجاز النهائي. الافتراضي `20` / `20` / `10`؛ والباقي يتوزع على الأدوار |

## مثال كامل

```json
{
  "quote_ref": "Q-2026-003",
  "date": "2026-08-03",
  "validity_days": 30,
  "project_name": "فيلا الأستاذ فلان",
  "client_name": "الأستاذ فلان الفلاني",
  "project_location": "حي المثال، المدينة",
  "floors": ["الدور الأرضي", "الدور الأول", "الملحق العلوي"],
  "area_m2": 820,
  "rate_per_m2": 630,
  "vat_percent": 15
}
```

## حقل `floors` — كيف يؤثر على المستند

كل عنصر في القائمة يصبح:
1. سطراً فرعياً ضمن البند رقم 10 من نطاق العمل ("أعمدة وأسقف الأدوار العلوية"،
   بصيغة: "{الدور}: صب الأعمدة الرأسية، تليها أعمال الشدة والتسليح وصب سقف {الدور}").
2. دفعة مستقلة في جدول الدفعات (القسم ثالثاً)، بنسبة محسوبة تلقائياً — انظر
   منطق التوزيع في تعليقات أعلى `scripts/generate_quote.py` (`compute_payment_shares`).
3. اسم يظهر في جملة "نسبة 1:1 (متر بمتر): سقف ..." ضمن منهجية القياس.

**الدور الأخير في القائمة** يُعتبر تلقائياً الدور الذي يكتمل به الهيكل، فتُلحق
بدفعته عبارة "وبئر المصعد، وأسوار الملكية" — إن لم يكن هذا مناسباً لمشروع
معيّن (مثلاً لا يوجد مصعد)، عدّلها يدوياً في الملف الناتج بعد التوليد.

## ناتج السكريبت (stdout)

يطبع السكريبت JSON بالأرقام المحسوبة (`subtotal`, `vat`, `total`,
`payment_shares_percent`, `payment_check_sum`) — تحقق دائماً أن
`payment_check_sum` يساوي `100.0` بالضبط قبل تسليم الملف.
